# 🔐 Day 5 - PyPassword Generator

## 📌 Project Overview

This is the **Day 5** project from the **100 Days of Code: The Complete Python Pro Bootcamp** by Dr. Angela Yu.

The **PyPassword Generator** creates a random password based on the user's preferences. Users can specify the number of letters, symbols, and numbers they want, and the program generates a secure password by randomly selecting characters from predefined lists.

This project introduces fundamental Python concepts such as:
- Loops
- Lists
- Random module
- String manipulation
- User input

---

## 🚀 How It Works

1. The user enters the desired number of:
   - Letters
   - Symbols
   - Numbers
2. The program randomly selects characters from predefined lists.
3. All selected characters are combined to form a password.
4. The generated password is displayed to the user.

> **Note:** In this version, the password is generated by placing all letters first, followed by symbols and numbers. (Later in the course, the characters are shuffled to create a more random password.)

### Example

```text
Welcome to the PyPassword Generator!

How many letters would you like in your password?
6

How many symbols would you like?
2

How many numbers would you like?
3

6 letters 2 symbols 3 numbers password must look like this:
aDfHtQ$#581
```
