# 🏝️ Day 3 - Treasure Island

## 📌 Project Overview

This is the **Day 3** project from the **100 Days of Code: The Complete Python Pro Bootcamp** by Dr. Angela Yu.

**Treasure Island** is a text-based adventure game where the player makes a series of choices to find the hidden treasure. Every decision affects the outcome, making it a great introduction to conditional logic and nested decision-making in Python.

This project focuses on using:
- Conditional statements (`if`, `elif`, `else`)
- Nested conditions
- User input
- String comparison
- Program flow control

---

## 🚀 How It Works

1. The player starts at a crossroads.
2. Depending on the chosen direction, the story continues or ends.
3. If the correct choices are made, the player reaches a house with three colored doors.
4. Choosing the correct door leads to the treasure, while the wrong choices end the game.

### Winning Path

```text
Left → Wait → Yellow
```

### Example

```text
Welcome to Treasure Island.
Your mission is to find the treasure.

You're at a cross road.
Where do you want to go?
Type 'left' or 'right': left

You've come to a lake.
Type 'wait' to wait for a boat.
Type 'swim' to swim across: wait

You arrive at the island unharmed.
There is a house with 3 doors.
One red, one yellow and one blue.
Which colour do you choose? yellow

You Win!
```
