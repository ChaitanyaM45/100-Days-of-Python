# 🎸 Day 1 - Band Name Generator

## 📌 Project Overview

This is the **Day 1** project from the **100 Days of Code: The Complete Python Pro Bootcamp** by Dr. Angela Yu.

The program generates a fun band name by combining:
- 🌍 The name of the city you grew up in
- 🐶 Your pet's name

It's a simple project designed to introduce beginners to Python basics like:
- `print()`
- `input()`
- Variables
- String concatenation

---

## 🚀 How It Works

1. The program welcomes the user.
2. It asks for the city where the user grew up.
3. It asks for the user's pet's name.
4. It combines both inputs to generate a unique band name.

### Example

```text
Welcome to the Band Name Generator.
What's the name of the city you grew up in? Pune
What's your pet's name? Bruno

Your band name could be Pune Bruno
```
