## 🐞 Types of Errors

During this day, I learned about common programming errors such as:

### Syntax Errors

Errors caused by incorrect Python syntax.

```python
if x > 5
    print("Greater")
```

### Runtime Errors

Errors that occur while the program is running.

```python
result = 10 / 0
```

### Logical Errors

The program runs successfully but produces an incorrect result.

```python
age = 20

if age < 18:
    print("Adult")
```

## 🔍 Debugging Techniques

Some useful techniques learned during this day include:

- Reading error messages carefully
- Reproducing the bug
- Checking assumptions
- Using `print()` to inspect variables
- Testing different inputs
- Examining code line by line
- Fixing one problem at a time
- Using a debugger when necessary
