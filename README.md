# 🐍 100 Days of Python

Welcome to my Python learning journey!

This repository contains all the projects I build while completing **100 Days of Code: The Complete Python Pro Bootcamp** by **Dr. Angela Yu** on Udemy.

---

## 🎯 Goal

Although the course is designed for 100 days, my goal is to complete **2–3 course days every day** while understanding each concept thoroughly.

By the end of this journey I aim to:

- Complete all 100 projects
- Master Python programming
- Learn automation
- Build desktop applications
- Build web applications
- Learn web scraping
- Learn APIs
- Learn databases
- Learn Data Science
- Learn Machine Learning
- Build a strong GitHub portfolio
- Prepare for internships and software development roles
