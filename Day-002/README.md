# 💰 Day 2 - Tip Calculator

## 📌 Project Overview

This is the **Day 2** project from the **100 Days of Code: The Complete Python Pro Bootcamp** by Dr. Angela Yu.

The program calculates how much each person should pay after adding a tip to the total bill. It allows users to enter the bill amount, choose a tip percentage, and specify how many people are splitting the bill.

This project introduces important Python concepts such as:
- Numeric data types (`int` and `float`)
- Mathematical operations
- User input
- Variables
- Rounding numbers
- f-Strings

---

## 🚀 How It Works

1. The program asks for the total bill amount.
2. The user selects the tip percentage (10%, 12%, or 15%).
3. The user enters the number of people splitting the bill.
4. The program calculates the total bill including the tip.
5. The total is divided equally among everyone.
6. The amount each person should pay is displayed.

### Example

```text
Welcome to the tip calculator!
What was the total bill? $150
What percentage tip would you like to give? 10 12 15 12
How many people to split the bill? 5

Each person should pay $33.6
```
