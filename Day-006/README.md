# 📚 Day 6 - Functions

## 📌 Overview

Day 6 of the **100 Days of Code: The Complete Python Pro Bootcamp** by Dr. Angela Yu focused on understanding **functions** in Python.

Instead of building a standalone project, this day was dedicated to learning how functions work and how they can be used to write cleaner, reusable, and more organized code.

The concepts were practiced through coding exercises and problem-solving challenges.

---

## 📖 Topics Covered

- Defining functions using `def`
- Calling functions
- Function parameters
- Function arguments
- Code reusability
- Breaking large problems into smaller functions
- Improving code readability and organization

---

## 💻 Practice

The exercises for this day were completed using coding challenges provided in the course (including Reeborg's World).

As this day focused on learning core programming concepts, there is no standalone project included in this folder.
